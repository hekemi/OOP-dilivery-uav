# UAV Delivery Lab

Streamlit-приложение для лабораторной работы по моделированию доставки заказов БПЛА.

## Запуск

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Модель

- город представлен графом 10×10, расстояние между соседями — 1 км;
- заказы генерируются по Пуассону в 3 точках (λ=5/ч, 08:00–20:00) и 10 точках (λ=0,1/ч, круглосуточно);
- все заказы имеют вес 1 кг, склад один, погрузка и выгрузка занимают 0 часов;
- дроны отправляются партиями до `N` заказов и возвращаются на склад;
- опционально учитываются максимальная дальность рейса и время зарядки;
- прибыль считается как `доход × доставленные заказы − стоимость километра × пробег`.

Планировщик использует жадную эвристику: сначала выбирается самый старый заказ, затем в рейс добавляются ближайшие заказы, пока не нарушены вместимость и ограничение дальности.
